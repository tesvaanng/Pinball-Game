# 第 0 章：給第一次讀這份文件的人

## 0.1 這是什麼專案

一款 Unity 彈珠遊戲。**最終目標是做成肉鴿（Roguelike）大數字遊戲**（類似 Peglin、Ballionaire、Balatro 的方向）。

但我們在開發過程中發現一個問題：**我們一直在「基礎玩法」還沒定的情況下，就往上面堆肉鴿設計**，導致討論混亂、無法判斷哪個設計是對的。

**所以本文件把肉鴿層完全拿掉，只定義最底層的彈珠遊戲。肉鴿層的設計另外記在 Pinball-Roguelike-Plan.md

## 0.2 本文件的核心原則

> ### 機制要完整，數值要微小。

基礎玩法必須是一個**完整的小遊戲**——機制五臟俱全，只是數字很小。
肉鴿層的工作是**放大**這個機制（數字變大），**不是解鎖**新機制。

**判斷標準**：把基礎玩法單獨拿出來玩，它是不是一個完整、好玩的小遊戲？
如果是，基礎玩法就對了；如果只有加上肉鴿才好玩，那基礎玩法有問題。

# 第 1 章：已定案的決策

## 1.0 一句話總結這個遊戲

```
拖曳瞄準方向 → 球從頂部發射器射出 → 打到釘子反彈（球上分數持續累積）
    → 落入底部袋口 → 實得分數 = 球上分數 × 袋口倍率
```

**參考座標**：
- **發射方式參考 Peglin**：頂部發射器、拖曳決定方向、球打到釘子反彈
- **盤面參考 Plinko**：均勻密集的釘子網格 + 底排一排倍率袋口

## 1.1 輸入

| # | 問題 | 決定 | 說明 |
|---|---|---|---|
| 1.1 | 玩家控制什麼？ | ✅ **瞄準方向（拖曳）** | Peglin 式 |

| 1.3 | 瞄準決定什麼？ | ✅ **球的初始方向** | **發射速度固定**（不像 Angry Birds 有力道維度） |
| 1.4 | 玩家能不能預先看到結果？ | ✅ **有預測線** | 見下方規格 |
| 1.5 | 有幾個輸入？ | ✅ **只有一個（拖曳瞄準）** | **沒有擋板**——這是 Peglin，不是傳統彈珠台 |

### 預測線的規格（對應上表 1.4 列）

| 元素 | 是否預覽 | 理由 |
|---|---|---|
| 球的飛行軌跡 | ✅ 是 | 讓玩家能規劃（這是瞄準的意義） |
| **牆壁反彈** | ✅ **是** | 牆是平的、可預測；而且**讓瞄準的表達範圍變寬**（可以瞄牆再彈回來） |
| **釘子碰撞** | ❌ **否，預測線停在此處** | 釘子是混沌的。若全部預覽，遊戲會變成確定性的解謎，沒有懸念 |

**設計意圖**：玩家能控制「球從哪裡進入釘子場」，但不能預測結局。這是懸念與技術的平衡點。

### ⚠️「無干預」的連鎖後果（極重要）

因為玩家在飛行期間**完全不能干預**，這帶來兩個必須遵守的設計約束：

| 約束 | 說明 |
|---|---|
| **① 球上飄字必須極度爽** | 玩家唯一的參與就是**盯著自己的分數在漲**。飄字不是裝飾，是**主要的參與機制**。M0 就要做好，不能留到最後 |
| **② 單球時長必須偏短** | 玩家沒事做，時間必須短（目標 3–8 秒，見 1.4.5） |

### ⚠️ 盤面幾何的關鍵警告（已確認的結論）

> **均勻的 Plinko 釘子網格，會讓「瞄準」完全失去意義。**

原因：Plinko 的網格設計目的就是**消除輸入的影響**——不管你從哪裡丟，結果都是同一條常態分布。這是 Plinko 作為賭博遊戲的特性。

但 Peglin 式瞄準的意義正好相反：**讓玩家控制結果**。

**兩者直接衝突。若直接用均勻網格，玩家會發現「怎麼瞄都差不多」，然後放棄瞄準。**

**已確認的結論**：盤面要**保留 Plinko 的視覺與手感**，但必須加入少量**結構元素**（分區擋板、漏斗、密度差異）來讓瞄準產生意義。**具體設計正在討論中（第 3 章）。**

## 1.3 計分 ⭐ 本設計的核心

| # | 問題 | 決定 |
|---|---|---|
| 1.3.1 | 分數怎麼算？ | ✅ **兩段式**：碰釘子加到「球上」；落袋後 `球上分數 × 袋口倍率` ＝ 真正獲得的分數 |
| 1.3.2 | 分數的意義 | 🟡 **基礎版純粹比高低**（顯示個人最佳分數），沒有其他用途 |
| 1.3.3 | 有連擊或倍率嗎 | ✅ **基礎版沒有連擊**（留給肉鴿層當 build） |
| 1.3.4 | 分數怎麼顯示 | ✅ **飄字跟著球**，見下方規格 |
| 1.3.5 | 數字會變很大嗎 | ⏳ **未定**（影響是否需要大數型別，見第 4 章） |

### 為什麼這是核心（設計引擎）

```
球上分數  = 潛在價值（靠彈跳累積，尚未兌現）
袋口倍率  = 兌現率
實得分數  = 球上分數 × 袋口倍率
```

**它產生三個效果：**

| 效果 | 說明 |
|---|---|
| **二階張力** | 球要**彈得久**（累積多）**且**要**落進高倍率袋**（兌現好）。**這兩件事可能互相衝突**（長球路可能導向低倍率袋）→ 這是本作的核心策略 |
| **袋口佈局 ＝ 盤面設計的全部** | 袋口倍率怎麼分布，直接決定這張圖好不好玩 |
| **它自動回答了「底部是目標還是死亡」** | 底部是**目標**（玩家想要高倍率袋），但**低倍率袋就是變相的懲罰** → 不需要額外設計懲罰機制 |

### 飄字規格（對應上表 1.3.4 列）

| 規則 | 內容 |
|---|---|
| 出現 | 該球**第一次加分**時，在球的位置顯示飄字 |
| 累加 | 後續每次加分，**累加到同一個數字上**，飄字跟著球移動 |
| 隱藏 | 一段時間沒有加分 → 飄字**隱藏** |
| **重要** | **隱藏時球上的分數仍在累積**，不是歸零。下次加分會重新出現並顯示完整值 |

## 1.4 結束與節奏

| # | 問題 | 決定 | 說明 |
|---|---|---|---|
| 1.4.1 | 一顆球的壽命怎麼結束 | ✅ **落入袋口即結束** | |
| 1.4.2 | 卡球／超時怎麼辦 | ✅ **超出一定時間 → 直接以 1 倍結算球上的分數** | 見下方說明 |
| 1.4.3 | 一「局」多長 | ✅ **固定球數**；🟡 **建議 20 顆** | 20 是建議值，見下方理由 |
| 1.4.4 | 有沒有「輸」 | 🟡 **建議：沒有**，只有總分與個人最佳 | |
| 1.4.5 | 節奏 | 🟡 見下方建議值 | |
| 1.4.6 | 有連擊嗎 | ✅ **沒有**（同 1.3.3） | |

### 為什麼「超時以 1 倍結算」很優雅

**一條規則同時處理三種狀況**：卡球、球無限彈跳、超時。
而且它**不嚴厲**——分數保留，只是失去袋口倍率（相當於沒進任何袋）。

附加好處：它**天然獎勵短球**，抑制了長球帶來的問題，與「無干預」的設計互補。

### 為什麼建議 20 顆球

若邊緣袋口倍率很高（例如 20×），**單顆球可能主導總分**。若一局只有 10 顆球、只有 1 顆進 20×，那局結果幾乎完全由那一顆決定。
**20 顆讓一局有足夠次數去追 jackpot**，那一顆 20× 就變成「**這一局的高潮**」而不是「**這一局的全部**」。

### 節奏建議值（對應上表 1.4.5 列）

| 維度 | 建議 | 理由 |
|---|---|---|
| 單球總時長 | **3–8 秒** | 玩家沒事做，時間必須短；1.4.2 的超時結算也天然獎勵短球 |
| 每秒碰撞次數 | **3–6 次** | 飄字是主要參與機制 → 數字要一直在跳 |
| 投球間隔 | **1–2 秒** | 讓玩家有時間決定下一個瞄準角度 |

> **兩個數字是連動的**：球飛 5 秒、每秒 4 次碰撞 ≈ 每顆球 20 次加分。這是飄字爽感的下限。

# 第 3 章：正在討論中

## 3.1 🔶 盤面幾何：Plinko 網格要加多少「結構」？

**現況**：已確認「**盤面參考 Plinko 可行**」，也確認「**純均勻網格會殺死瞄準**」（見 1.2.4 的警告）。

**正在討論的問題**：要加哪些結構元素、加多少？

**AI 的提案**（尚未經使用者確認）：

| 保留 Plinko 的 | 加上結構 |
|---|---|
| 均勻交錯的釘子網格（視覺與手感） | **2–4 條分區擋板**（把盤面切成走廊） |
| 密集的釘子（讓飄字跳得爽） | **幾個漏斗**（導向特定袋口） |
| 一排倍率袋口 | **不同區域的釘子密度**（密集＝累積多、稀疏＝通過快） |

**提案的關鍵數字**：結構元素只佔盤面 **5–10% 的面積**——**90% 看起來還是 Plinko，但那 10% 決定遊戲有沒有技術成分。**

**已識別的具體陷阱**：如果「空曠區」直通高倍率袋口，它就變成必勝路線，取捨消失。
→ **原則：「空曠」的代價必須是「不可控」，不是「又快又好」。** 空曠區必須短，且下方要接一段密集區把球打散。

**待使用者回應**：是否採用此提案？要畫哪一版？

## 3.2 🔶 袋口佈局：數量與倍率

**現況**：已確認「底排袋口」，數量與倍率值**未定**。

**已提出的選項與建議**：

| 項目 | 選項 | AI 建議 |
|---|---|---|
| 袋口數量 | 6 / 8 / 9 個 | **8 個**（對稱好排；Plinko 經典是 9 個） |
| 倍率分布 | 中央低兩側高（Plinko 式） | **中央低、兩側高**——因為 Plinko 落點接近常態分布，中央最容易進所以最不值錢 |
| 最低倍率 | 是否有 0× / 0.5× | **不要 0×**（1.4.2 已有懲罰，再加 0× 太挫敗）。0.5× 可作為「陷阱袋」 |
| 最高倍率 | 10× / 20× / 更高 | 20×，作為稀有高潮 |

**已識別的問題**：高倍率袋口會造成**高變異數**（單顆球主導總分）→ 已建議用 20 顆球來平滑（見 1.4.3）。
